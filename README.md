# 拾词

商品素材整理分为两种用法：

- **预处理独立版**：自带Python运行环境，解压后双击“启动预处理.cmd”。只做CSV导入/基础去重，可选embedding相似排序，不调用生成式LLM。结果、原始CSV、完整JSON和可复制的Skill续做提示词保存在工作区。之后由能读写文件的AI直接执行Skill。
- **旧本地完整流程（历史项目）**：双击“启动工作台.cmd”，使用硅基流动模型逐阶段处理。此包需要Python3.10+；旧项目保持原格式。

新项目最终四份Excel：本品资料与页面改动建议、QA与A+问答、投放分级关键词与问句、描述素材。空模板在templates。当前Skill按本品资料、投放词句、QA与A+、描述素材四块执行；每块先补材料表单，填完发“1”执行，块内连续完成。最终四表完成后清理agent生成的临时JSON，原始输入和预处理接手材料保留。资料、当前子体、本次投放与文案可用性分别判断，本次不投的词可留作有依据的文案或恢复到其他已确认子体。

Skill位于skills/listing-material-workflow/SKILL.md；操作见本地工作台使用说明.md。预处理程序只做机械整理，agent不运行本地语义工作流代跑。

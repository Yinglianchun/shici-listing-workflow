# 开始前的本品分析

从完整标题、五点、参数、本型号A+及用户明确确认内容，提炼定位、核心卖点、适用人群和场景。每条附对应原文，并可说明回应了什么买家关注点；不从竞品、AI拓词Evidence或品类常识补事实。商品页已有定位和普通用途可以保留，不额外要求独立研究。

用00_本品分析.xlsx模板的三张Sheet：本品分析（类别、要点、原文依据、关注点）、资料差异（字段、原文一、原文二、差异、建议）、待补资料（待补内容、原因）。资料差异中分“冲突”与“口径待统一”，保留两段对应原文；程序分别保存conflicts与pending_unification。空表可留空，不制造冲突凑表。完整原文仍在00_本品资料.xlsx与product.json，不用摘要替代。

区分三类：两段原文确实不一致、定位或适配口径需要统一、资料尚缺。用户写在待确认里的疑问并非已经成立的冲突。集中提出关键问题，其他已知部分照常继续；用户确认新卖点后同步完整资料，并提示页面是否需要更新。

眼镜例子：140mm框宽不能直接推翻小脸定位，但标题“小/窄脸”和五点“中小椭圆脸”的口径可列待统一；非偏光与页面列日常驾驶用途不构成文字矛盾；UV防护和偏光分别核对。镜框形状不同于适配脸型，框色不同于镜片色，套戴近视镜不同于自带矫正度数。例子不为其他商品预设参数。

完整流程先做本品分析。仅01基础整理或02排序时可暂缓，在进入AI去重、适用性筛选或选QA前补做。程序保存product_analysis.json供筛选和QA参考，原文优先；人工环境直接交付真实Excel即可，不强制额外JSON。

不要照搬外部skill的搜索量等级、性别核心词、否定词建议或未核对的索引权重来覆盖本项目规则。

# 各阶段维护四份Excel

由当前agent自己执行，不运行本地工作流或调用其他LLM代跑。读写表格与基础统计可用工具。新项目使用四份空模板，逐步更新本品资料与建议、QA与A+、投放分级词句、描述素材，不另增阶段Excel。

| 阶段 | 更新内容 |
|---|---|
| 00 本品分析 | 可只给ASIN/链接，由agent先读页面及可查看的图片；读全五点后，反问图片是否还有未补充信息及现有QA/A+/页面外卖点；整理定位卖点、人群场景、资料差异与缺失；新增00的旧任务补做即可 |
| 01 基础去重 | 统计摘要；完整来源和原文保留在输入及过程记录 |
| 02 排序 | 更新统计与比较进度；相似度不是重复结论，不删原文 |
| 03 适用性 | 分本品事实、子体、投放与文案；另存04b本次投放排除，可恢复原文；具体规格与已知事实冲突的词句退出候选；中性功能确认原问保留；未知属性在当轮集中追问，不另建待补/待确认表 |
| 04 高重合去重 | 只看原始Keyword文本，返回原文映射；关键词新增限定不删，问句严格完整包含才删短句；仅在已确认适用且子体、投放/文案范围一致的可用池比较，待确认和不适用长句不得替代适用短句 |
| 05 核心词汇总与补泛词 | 先读全部CSV的核心字段、用户此前/当前清单、参考表和本品资料；核对适用范围，汇总去重、补齐常用泛词和有依据的单一限定候选，记录来源并固定核心口径；本步不批量分级，找不到用户提及的历史清单先追问 |
| 06 方向分级、关键表达与广告词库 | 05核心与补词完成后，分类并按独立语义属性分级；所有问句素材提炼关键表达填Keyword，C列保留原问；核对条件、等级，清A列标点后去重，完成所有等级页、正向投放、本次排除及否定候选；0/1级精准否定候选 |
| 07 独立QA | 从完整原问池及未分类原问选题，包含03未用于广告的原问；卖家口吻、目标10条主QA/备选及2—3条A+；分别尽量240—250/480—500字符；主QA与A+含副标题分别检查他牌 |
| 08 描述复核与前缀 | 描述候选再次对照本品后归并前缀；不改完整广告词，不因文案未选就删广告词，发现原始事实错误才据依据更正03 |
| 09 描述 | 先按定位与卖点建立框架，按短语在描述里的角色归类，不平均配额；9000为每组上限，超出分多组，保留有效素材；每组记录长度及目标父/子ASIN和适用范围，未确认先待分配，保存同一份描述素材Excel |

一轮只完成一个步骤，落表、更新续做记录、给下一步提示词后停下等用户继续；当前缺资料先追问，不自动跳步骤。先完成05汇总补词，再完成06分级与广告词库，再做07独立QA。旧程序stage3/4可能是去重/适用性，stage6/7/8是QA/清洗/广告与前缀，按实际内容映射本表，不按旧编号认定完成。

## 续做输入

00更新本品资料表，01—06更新投放分级词句，07更新QA表，08—09更新描述素材；其他相关表同步更新。这是按阶段回填，不是缺文件。先读本品完整资料和00分析，再读总表已填区域；程序已有stageN.json可作为对应阶段的完整输入。03筛选表可用代表不等于全部原问，相关功能确认原问和去重变体可供QA参考，已知具体规格错误的原问不重新当QA候选。来源计数不等于搜索量。

程序模式尚未提炼时，问句表A列留空、原问列填完整问题并标“待06提炼关键表达”；提炼后才填A列，不能拿仅去问号的原问冒充关键表达。短问句和长问句采用同一原则，必要的for/with等关系保留；QA正式问题保持完整。旧Level与Evidence只留档。

最终四份Excel：本品资料与页面改动建议、QA与A+问答、投放分级关键词与问句、描述素材；过程文件保留。阶段中断时保存总表，并在项目过程记录里写清已完成步骤、下一阶段、先读哪些输入。旧多文件项目按stage-files-legacy.md及其项目原进度续做，不把新模板倒套旧文件。

预处理先01/02、agent接手补00再03；从原始CSV直接做的agent先00。资料新增或口径改变后回看受影响的判断与答案，不仅重新拼接09。07与09完成后回填共用场景的QA编号、描述落点及五点建议位置；只有建表或列场景不表示三处已同步，缺失关联标待回填。

# 各阶段维护四份Excel

由当前agent自己执行，不运行本地工作流或调用其他LLM代跑。读写表格与基础统计可用工具。新项目使用四份空模板，逐步更新本品资料与建议、QA与A+、投放分级词句、描述素材，不另增阶段Excel。

| 阶段 | 更新内容 |
|---|---|
| 00 本品分析 | 先问未提供的现有QA/A+及页面外实物卖点；读全五点，整理定位卖点、人群场景、资料差异与缺失；新增00的旧任务补做即可 |
| 01 基础去重 | 统计摘要；完整来源和原文保留在输入及过程记录 |
| 02 排序 | 更新统计与比较进度；相似度不是重复结论，不删原文 |
| 03 高重合去重 | 只看原始Keyword文本，返回原文映射；关键词新增限定不删，问句严格完整包含才删短句 |
| 04 适用性 | 分本品事实、子体、投放与文案；另存04b本次投放排除，可恢复原文；待确认先问 |
| 05 方向与分级 | 从原问归纳方向；0-1、2、3、4及以上的关键词与问句分表，当前属性和等级重算 |
| 06 独立QA | 卖家口吻直接回答；目标10条主QA、备选、2—3条A+；QA尽量240—250字符、A+480—500字符，分别不超250/500；有汗液腐蚀/接触过敏/抗刮原问时优先选1—2个 |
| 07 清洗复核 | 问句表A列填清洗文本，原问完整保留；功能活动及穿搭/派对/购物/社交用途都要判断；最终筛选刷新等级页 |
| 08 广告素材 | 0/1级精准否定候选，词组否定与其他否定候选单独整理；正向词句保持完整 |
| 09 描述 | 先按定位与卖点建立框架，按短语在描述里的角色归类，不平均配额；优先高价值信息，9000字符内保存描述素材Excel并记录长度 |

## 续做输入

00更新本品资料表，01—05/07—08更新投放分级词句，06更新QA表，09更新描述素材；其他相关表同步更新。这是按阶段回填，不是缺文件。先读本品完整资料和00分析，再读总表已填区域；程序已有stageN.json可作为对应阶段的完整输入。04表可用代表不等于全部原问，待确认原问和去重删除的变体仍供QA参考。来源计数不等于搜索量。

程序模式尚未清洗时，问句表A列留空、原问列填完整问题并标“待07清洗”；清洗后才填A列，不能拿仅去问号的原问冒充清洗结果。旧Level与Evidence只留档。

最终四份Excel：本品资料与页面改动建议、QA与A+问答、投放分级关键词与问句、描述素材；过程文件保留。阶段中断时保存总表，并在项目过程记录里写清已完成步骤、下一阶段、先读哪些输入。旧多文件项目按stage-files-legacy.md及其项目原进度续做，不把新模板倒套旧文件。

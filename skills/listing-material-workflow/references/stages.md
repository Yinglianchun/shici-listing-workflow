# 各阶段回填同一份总表

由当前agent自己执行，不运行本地工作流或调用其他LLM代跑。读写表格与基础统计可用工具。新项目从assets/素材总表空模板.xlsx开始，每完成一步就更新保存同一个Excel，不另产阶段文件。

| 阶段 | 更新内容 |
|---|---|
| 00 本品分析 | 本品资料、定位卖点、人群场景、资料差异、待补资料、否定方向建议；固定词组与建议分开 |
| 01 基础去重 | 统计摘要；完整来源和原文保留在输入及过程记录 |
| 02 排序 | 更新统计与比较进度；相似度不是重复结论，不删原文 |
| 03 高重合去重 | 只看原始Keyword文本，返回原文映射；关键词新增限定不删，问句严格完整包含才删短句 |
| 04 适用性 | 已剔除-附原因、待确认素材、子体备用；分别统计代表和删除留档原问 |
| 05 方向与分级 | 从原问归纳方向；0-1、2、3、4及以上的关键词与问句分表，当前属性和等级重算 |
| 06 独立QA | QA、A+、原问关联、完整原问池；每方向一问，清洁可单独归类 |
| 07 清洗复核 | 问句表A列填清洗文本，原问列完整保留；本品最终筛选同步刷新等级页 |
| 08 广告素材 | 0/1级精准否定候选，词组否定与其他否定候选单独整理；正向词句保持完整 |
| 09 描述 | 从可用清洗素材组合不超过9000字符的一段描述，保存真实Word；总表记录字符数 |

## 续做输入

总表模式下所有步骤的Excel路径可以相同，这是按阶段回填，不是缺文件。先读本品完整资料和00分析，再读总表已填区域；程序已有stageN.json可作为对应阶段的完整输入。04表可用代表不等于全部原问，待确认原问和去重删除的变体仍供QA参考。来源计数不等于搜索量。

程序模式尚未清洗时，问句表A列留空、原问列填完整问题并标“待07清洗”；清洗后才填A列，不能拿仅去问号的原问冒充清洗结果。旧Level与Evidence只留档。

最终只交一份总表Excel和一份Word。阶段中断时保存总表，并在项目过程记录里写清已完成步骤、下一阶段、先读哪些输入。旧多文件项目按stage-files-legacy.md及其项目原进度续做，不把新模板倒套旧文件。

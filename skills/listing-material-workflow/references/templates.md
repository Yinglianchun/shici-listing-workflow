# 当前四份Excel模板

新项目使用以下assets模板，项目数据留空，投放表保留类型排除和词组否定预置；中间用临时JSON，按内容完成情况生成或更新同一组四份文件：

- [本品资料与页面改动建议空模板.xlsx](../assets/本品资料与页面改动建议空模板.xlsx)：完整原文与用户补充分列，含本品分析、资料差异、页面与补充口径、五点修改建议、需同步的页面字段、共用场景清单及本次投放策略。
- [QA与A+问答空模板.xlsx](../assets/QA与A+问答空模板.xlsx)：目标10条主QA、备选QA、备选原问、2—3条A+、原问关联与完整原问池；QA尽量240—250、A+480—500英文字符，不超限、不造信息凑满，卖家角度回答。
- [投放分级关键词与问句空模板.xlsx](../assets/投放分级关键词与问句空模板.xlsx)：沿用参考模板的0-1、2、3、4级及以上关键词/问句分表，当前属性重算。含否定、子体备用、事实排除及04b本次投放排除。普通成人太阳镜模板已预填运动及儿童眼镜完整词组。“已剔除-附原因”里的预置规则行不计入实际剔除统计；实际命中另记完整原词句。“词组否定”预置按本品类型保留并去重。本品支持但本次不投的词不混入正向候选，也不从可用文案删除。
- [描述素材空模板.xlsx](../assets/描述素材空模板.xlsx)：每组一行，9000为每组上限，超出继续分组；含字符数、组号、目标ASIN、父体/子体、适用范围与分配状态，采用明细关联组号；单条超长保留待整理。正文按采用明细逐条原样拼接，条目间只加分号和空格，附加说明和理由放在明细或依据区。按已确认父子体核对适用性后分配，未确认先留空，不另交Word。

投放问句A列Keyword统一填提炼后的关键表达，不分问句是否超过80字符，不仅去问号或机械删除所有虚词；C列始终保留完整原问。去掉提问外壳，保留核心、属性、用途、否定、数字、条件及必要关系（如for/with/without/fit over）。06提炼前A列留空；长度对应实际A列，旧Level和Evidence只追溯。QA表正式问题仍是完整问句。颜色区分框/片，尺寸区分部件/单位，品牌原文可在排除留档中保留，最终表达去已确认他牌，保留自家品牌。词组否定页记录诸如阅读镜、近视镜本身等明确不符的商品类型、挡掉的意图和理由。

等级页的Modifiers填实际参与计级的英文短语，并以“ + ”连接。例如 `90s + for women + lightweight` 或 `classic + full frame + for women`。同一方向下的不同限定分别列出，等级以独立限定数为准。核心内限定不重复写，裸核心留空，中文解释放依据或备注。

广告词句文件所有工作表的A列数据，在生成时去掉英文/中文逗号及直/弯单引号（,，'‘’）。分隔逗号换空格，单引号删除，多余空格合并；数值含义和否定条件不能因此改变，否定缩写先展开。确定最终分表后按清理后的A列再次去重和计算长度。包含关系只用在同一张最终投放Sheet内，相邻或不同等级Sheet之间不因包含而删短词句。原文留档列保留原标点，QA/A+表不执行此规则。0/1级精准否定候选可各列实际出现且应否定的不同词序，订单按原条保留。2级及以上广泛投放，对关键词和问句A列共同核对，仅调序而无新增含义的表达只列一个投放代表；变体和原文关联另记依据。

保留各模板的表头位置和列顺序，不冻结；表头16.5、正文14或28，紧凑列宽，描述长文本完整保存在单元格。阶段重复执行替换对应区域，不追加编号Sheet或重复统计，保留其他阶段与用户修改。辅助脚本修改前留副本或Git版本、改后检查语法并实际执行。

其他空表仅供明确采用旧格式的项目续做，见stage-files-legacy.md。原始用户文件保留；本项目中间JSON仅暂存，四份Excel全部完成后清理，不额外交付日志或阶段文件。

07在本品资料基础上分别重写QA和A+问答。已提供的QA/A+和其他材料供提取本品依据。主QA填QA区，英文回答最多250字符；A+英文回答按500字符预算写，最多500字符。A+备用展示问句挑最合适的方向，结合本品依据提炼成一句自然问题。展示内容只留问句，原始素材与关系另在原问池或关联列留存。

按四块完成本品资料、投放词句、QA与A+、描述素材；每块先读已有材料，有缺项才由agent即时生成聊天表单，补齐后发“1”执行。材料齐全时直接提示发“1”。块内连续完成，更新对应Excel后等待下一块。0/1级关键词页需包含本品适用的通用词及有依据的常见一级词，不限于原CSV裸词；补充项注明本品资料归纳及依据，不虚构旧Level或出现次数。不以词少为由降级、过度补词或撤销去重。

05先读取全部CSV、用户此前/当前核心词清单与历史参考表，汇总并补泛词，固定核心口径；06再分级并完善广告词库，不先分级再补词。来源不明先追问，不能只用CSV里的核心词。可选机械清洗脚本见mechanical-cleaning.md，脚本结果供后续步骤和最终四份Excel使用，中间不必导表。

不生成独立待补资料、待确认素材或答案待补工作表。处理到资料缺项时，agent在当轮对话集中询问属性及对应部件/子体，确认后再更新结果；未答项暂存临时state.json。已知具体规格冲突的词句退出后续候选，原始来源保留；中性功能确认问句可留，广告衍生词另按本品事实核对。

每份最终工作簿和四份空模板首页为“使用说明”，简短说明用途及填写位置；本品资料表另有“确认表单”，由agent按所属大块记录已确认事项及依据，供后续复用。用户在聊天里补缺项。生成时移除Level(源表)、出现ASIN数、涉及ASIN/来源（含涉及ASIN）列；目标ASIN、本品ASIN、子体及完整原问保留。材料与表单见intake-and-materials.md。

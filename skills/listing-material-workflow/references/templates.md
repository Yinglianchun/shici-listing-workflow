# 当前四份Excel模板

## 当前缩句与交付结构

描述稿每版上限20,000字符（含空格和标点），优先将全部已采用素材按原样分号拼接为一版；超过20,000字符时再按完整条目分成两版，每版各自不超限。两版是拆分结果，不是重复生成两套同义稿。不能为只出一版丢掉有效素材；两版仍放不下时先保留未安排素材在步骤备份并请用户确认后续分配。

**本节为当前模板与文件存放规则；下文及旧参考中的列数、资料存放和展示页要求按本节执行。**

- 问句等级页保留A Keyword、B 属性数、C 核心词、D Modifiers、E 原问句、F 描述用清洗表达，新增G「自然投放候选」，不增加素材类型列。A列沿用80字符/10词分流：短问仅去问号；长问原地缩句，只删除提问外壳及冗余成分，保留剩余词的原始相对顺序，不改写、不换词或调换属性位置，保留具体属性、评价限定、否定、数值、部件和条件及必要关系。G列对所有相关原问另写自然的投放候选，可调整词序、补必要介词，须保留全部实质限定；不得覆盖A/E/F，也不以G列词序决定A列去重或属性等级。G列仍独立核对本品事实与适用范围。
- 例：原问 `Are these sunglasses men can wear with a rectangular frame trendy for a Y2K style?`；A列原地缩句可为 `sunglasses men rectangular frame trendy Y2K style`；G列自然候选可为 `trendy rectangular frame sunglasses for men in a Y2K style`。两列均保留men、rectangular frame、trendy、Y2K style，不能遗漏trendy。A列是按原序删减的结果，不要求它成为自然英文句子。F列仍是经事实核验的描述用表达，供08/09使用。
- 最终仍交四份Excel。第一份文件沿用“本品资料与页面改动建议”命名，但只保留「商品详情改动建议」「五点修改建议」两页，均列目标ASIN/子体、位置、原来的描述、建议文案、改动理由；原文无改动时明确无需改动，缺失原文留空，不编写原文。建议文案与理由基于过程资料中的已确认事实。
- 完整本品资料、事实基准、分析、资料差异、确认表单、页面与补充口径、共用场景及投放策略均放入「步骤备份/00_本品资料/本品过程资料.xlsx」，使用assets中的「00_本品过程资料空模板.xlsx」。后续各块确认也更新此过程文件；03、07及08/09从这里读取事实和确认结果。下文所称写回本品资料表的完整资料/确认事项，均指此过程文件，不再写进最终建议表。过程文件随步骤备份保留，不作为第五份正式交付。
- 最终描述工作簿只保留「描述素材」「采用明细」两页；「描述素材」每组一行，保留全文、字符数、每组上限、组号、目标ASIN、父子体、适用范围及分配状态。「采用明细」关联组号并列出实际采用的完整条目。未采用、单条超长或待整理素材只保留在08/09步骤备份，不在最终工作簿建立「待整理素材」或「使用说明」页；20000字符上限及原样分号拼接规则继续执行。
- 「素材总表」只作为过程文件或内部数据，不再独立交付或在最终文件中重复展示同一词池。最终「投放分级关键词与问句」为投放词句的唯一交付表；完整来源、语义映射、排除及过程素材保留在步骤备份，供QA与描述继续读取。现有历史总表保留，新项目不额外交付总表。
- QA与A+结构不变。第一份建议表及描述表按上述两页结构精简，使用说明写入模板说明文档；不套用旧版“每份最终Excel必须有使用说明页”的要求。



新项目使用以下assets模板，项目数据留空，投放表保留类型排除和「词组否定」Sheet预置（仅词组匹配，候选待审，不自动投放；0～1级精准否定保留在对应等级页）；中间用临时JSON，按内容完成情况生成或更新同一组四份文件。**当assets或已有工作簿仍为旧版独立0级/1级分表时，先转换成当前0～1级按类型两张合页，再开始写入，禁止沿用旧Sheet结构**：

- [本品资料与页面改动建议空模板.xlsx](../assets/本品资料与页面改动建议空模板.xlsx)：完整原文与用户补充分列，含本品分析、资料差异、页面与补充口径、五点修改建议、需同步的页面字段、共用场景清单及本次投放策略。
- [QA与A+问答空模板.xlsx](../assets/QA与A+问答空模板.xlsx)：目标10条主QA（眼镜项目第1—5条讲眼镜本身，第6—10条讲人群与佩戴）、备选QA、备选原问、2—3条A+、原问关联与完整原问池；QA尽量240—250、A+480—500英文字符，不超限、不造信息凑满，卖家角度回答。
- [投放分级关键词与问句空模板.xlsx](../assets/投放分级关键词与问句空模板.xlsx)：采用「0～1级-关键词」「0～1级-问句」两张合级展示页，加上2级、3级、4级及以上各自的关键词/问句页，共8张。0级和1级只合并展示位置，B列属性数仍逐条保留0/1；0级词与问句按素材类型分入对应页，不再混排，不另设G列素材类型，禁止跨关键词与问句去重；含否定、子体备用、事实排除及04b本次投放排除。普通成人太阳镜模板已预填运动及儿童眼镜完整词组。“已剔除-附原因”里的预置规则行不计入实际剔除统计；实际命中另记完整原词句。“词组否定”预置按本品类型保留并去重。本品支持但本次不投的词不混入正向候选，也不从可用文案删除。
- [描述素材空模板.xlsx](../assets/描述素材空模板.xlsx)：每组一行，20000为每组上限，超出继续分组；含字符数、组号、目标ASIN、父体/子体、适用范围与分配状态，采用明细关联组号；单条超长保留待整理。正文按采用明细逐条原样拼接，条目间只加分号和空格，附加说明和理由放在明细或依据区。按已确认父子体核对适用性后分配，未确认先留空，不另交Word。

问句先按06标准去重选代表，再按代表原问的字符数和单词数分流投放A列：**<80字符且≤10个英文单词**只去问号，保留其他词与标点；**≥80字符或>10个英文单词**就提炼投放关键表达并执行普通标点清理（保留`non-polarized`等连字符）。**E列完整保存原问，F列独立保存「描述用清洗表达」供08/09使用**，不分问句长短都需另行清洗并核对适用性；C列仍为核心词。旧项目若使用不同列序，按实际表头对应，不可盲用固定列字母。F列的描述清洗表达需去掉提问外壳，保留核心、属性、用途、否定、数字、条件及必要关系（如for/with/without/fit over）。06处理前A/F列留空；原问的80字符与10词双门槛均在清洗前计算（英文词项按空白分隔，词内连字符不拆分），实际A列长短另行内部检查，但不在问句分级页展示长度列，旧Level和Evidence只追溯。QA表正式问题仍是完整问句。颜色区分框/片，尺寸区分部件/单位，品牌原文可在排除留档中保留，最终表达去已确认他牌，保留自家品牌。词组否定页记录诸如阅读镜、近视镜本身等明确不符的商品类型、挡掉的意图和理由。

分级后重写Modifiers，按顺序填核心外的英文限定，用加号连接，如 `classic + full frame + for women`。裸核心留空，中文理由写依据或备注。

关键词及长问投放A列清除无意义标点（不改变单词/数值/否定关系），**保留词内连字符`-`**；否定缩写先展开，数字小数点、单位等保留必要语义。短问A列按特殊规则只去`?`/`？`，其余标点保留。长度按清理后的A列内部计算但不展示长度列。判重依据本Sheet完整A列投放表达，问句额外核对E列原问：06先确定完整核心词、属性短语及修饰对象。属性与核心词前后位置不同即保留（`14cm arm length sunglasses` 与 `sunglasses with 14cm arm length`）；属性位于同一侧且内部顺序调整、单复数/所有格/连字符/词形变体经核实语义完全无损时可合并（`adjustable silicone nose pads sunglasses` 与 `silicone adjustable nose pads sunglasses`）；同侧仅差非必要介词也可合并（`sunglasses with 14cm arm length` 与 `sunglasses 14cm arm length`）。必须核对数字、单位、否定、限定条件、修饰对象完全一致；颜色挂到不同部件、`with`对`without`、普通近义词改写不可盲并。裸核心等价写法可在同类型同范围中归并。不能用旧Modifiers或同等级取代原文核对；合并保留来源映射。

投放等级页使用精简列顺序：「0～1级-问句」及2级以上问句页为A Keyword、B 属性数、C 核心词、D Modifiers、E 原问句、F 描述用清洗表达；「0～1级-关键词」及其他关键词页为A Keyword、B 属性数、C 核心词、D Modifiers、E 原文。0级与1级在对应素材页合并展示但属性数独立计算，分别保留0或1。全部8张等级页均删除展示用「来源行」「分组ID」「处理」三列，完整明细只保存在步骤备份的追溯、合并映射、复核和排除记录中。属性数由低到高排序；移除等级页的旧长度、Intent、Evidence、投放建议和语义复核列，但原Evidence仍留原文追溯。其余模板按各自原有列序保留。不冻结；表头16.5、正文14或28，紧凑列宽，描述长文本完整保存在单元格。阶段重复执行替换对应区域，不追加编号Sheet或重复统计，保留其他阶段与用户修改。辅助脚本修改前留副本或Git版本、改后检查语法并实际执行。

其他空表仅供明确采用旧格式的项目续做，见stage-files-legacy.md。原始用户文件保留；每一步的过程JSON或表格副本保留在“步骤备份/”下对应步骤的子目录。四份正式Excel放在“最终输出/”，需清理时可单独删除整个“步骤备份/”。

**最终校验**：A/E/F每格只放一条表达，禁止拼接`问题A | 问题B`。合并变体只保留追溯映射，未满足去重条件的问句独立成行；导出扫描只是兜底，原始Evidence/Modifiers中的合法竖线不应删除。

07在本品资料基础上分别重写QA和A+问答。已提供的QA/A+和其他材料供提取本品依据。主QA填QA区，英文回答最多250字符；A+英文回答按500字符预算写，最多500字符。A+备用展示问句挑最合适的方向，结合本品依据提炼成一句自然问题。展示内容只留问句，原始素材与关系另在原问池或关联列留存。

按四块完成本品资料、投放词句、QA与A+、描述素材；每块先读已有材料，有缺项才由agent即时生成聊天表单，补齐后发“1”执行。材料齐全时直接提示发“1”。块内连续完成，更新对应Excel后等待下一块。「0～1级」两页中需核对属性数为0的完整核心表达确实没有独立限定；属性数为1的关键词需包含本品适用、有依据的常见单项限定词，不限于原CSV裸词；补充项注明本品资料归纳及依据，不虚构旧Level或出现次数。不以词少为由降级、过度补词或撤销去重。

05先读取全部CSV、用户此前/当前核心词清单与历史参考表，汇总并补泛词，固定核心口径；06再分级并完善广告词库，不先分级再补词。来源不明先追问，不能只用CSV里的核心词。可选机械清洗脚本见mechanical-cleaning.md，脚本结果供后续步骤和最终四份Excel使用，中间不必导表。

不生成独立待补资料、待确认素材或答案待补工作表。处理到资料缺项时，agent在当轮对话集中询问属性及对应部件/子体，确认后再更新结果；未答项暂存临时state.json。已知具体规格冲突的词句退出后续候选，原始来源保留；中性功能确认问句可留，广告衍生词另按本品事实核对。

**最终输出精简**：投放分级工作簿保留使用说明、当前统计、必要时合并的本品事实与核心口径、各级关键词/问句页、一张按共同决策方向合并的「待确认事项」，以及**必需的「词组否定」Sheet**。「0～1级-关键词」「0～1级-问句」本身就是对应的精准否定清单，不重复汇入「词组否定」或其他否定页。「词组否定」只放否定词组，匹配方式固定为词组匹配，记录所排除意图、潜在误伤与审核状态；不放完整问句或精准否定候选。如有0～1级两张等级页之外的额外精准否定候选，另设「额外精准否定」Sheet，仅使用精准匹配；预置条目只能作为候选，不能自动当成已投放否定。事实不符先在03排除正向/文案，不能机械升级成否定。这张表按本品证据待确认/模型语义待重读分别标识处理人，列待确认的问题、关联条数和少量代表原文；只有真实未完成事项进入其中，已知事实冲突和仅供QA的原问不再占用待确认。逐行原文追溯、QA完整原问池、语义合并映射、已剔除及子体备用移入步骤备份供07与后续复核读取，不重复放在最终交付Excel。只做规则演示的Sheet不要交付；不生成原CSV旧Level对照Sheet，也不显示旧终审逐级数量对照。归并后每条来源和去向仍要能在备份中恢复。

每份最终工作簿和四份空模板首页为“使用说明”，简短说明用途及填写位置；本品资料表另有“确认表单”，由agent按所属大块记录已确认事项及依据，供后续复用。用户在聊天里补缺项。生成时移除Level(源表)、出现ASIN数、涉及ASIN/来源（含涉及ASIN）列；目标ASIN、本品ASIN、子体及完整原问保留。材料与表单见intake-and-materials.md。

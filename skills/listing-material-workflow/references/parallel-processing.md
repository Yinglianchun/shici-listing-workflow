# 大批量CSV并行整理与复核

多份初始CSV或大量关键词、问句适合由多个子代理并行处理，主代理统一本品事实、核心口径、跨表合并与最终写表。初始CSV不需要已有等级，不把来源表的旧Level当作分派或定级依据。并行只改变任务分配，不跳过00—06的事实与核心确认依赖。

## 平台与模型

在ChatGPT Work或Codex中，使用平台原生子代理；执行本流程的整理与复核子代理指定为 **GPT-6.1 Terra，中等思考**（工具参数支持时为`model: gpt-6.1-terra`、`reasoning_effort: medium`）。此型号与思考档要求仅适用于这两个平台，其他agent、AI或聊天模式不要求采用此设置。平台不支持子代理时由当前agent完成相同处理；支持子代理但无法指定该型号或思考档时，说明实际可用设置，不声称已使用指定设置。不为此调用外部LLM API。

## 分派前的共同输入

主代理先读取全部CSV的结构及CoreTerm/Category等显式核心候选，完成00本品事实和初始核心确认。给每条来源记录保留稳定标识、文件名、原始行、完整关键词或原问；去重后的代表记录保留全部来源映射。所有子代理收到同一份最新事实基准、主推子体、品牌及投放取舍、用户确认核心、相关分级与去重规则。新增未知事实由主代理汇总提问，子代理不自行猜补或各问一次。

## 按依赖分轮处理

1. **初始CSV分片整理。** 通常按每张初始CSV分派一个任务；大小悬殊时可拆大表或合并小表，并按来源标识核对覆盖。子代理区分关键词与完整问句，按01只合并表内规范化后完全重复，保留原文和全部出处，组织02比较候选并逐条核实03本品相关性、事实、子体、广告与文案用途。主代理汇总后完成跨CSV的01完全重复合并与02候选组织；同一条跨表重复的事实判断有分歧时先裁定。此轮不因尚未确认的核心、旧等级或宽泛程度删除词句。
2. **统一候选与核心。** 主代理组织跨CSV的04比较，按05补齐并固定全局核心及有依据的新增词。新增词补做03核验。05固定核心前，不产出正式等级页；可并行核查事实或整理候选，不让各CSV自行扩核心来降低等级。
3. **并行提炼与分级。** 固定核心后，可沿用CSV来源分片，把跨表合并的代表记录分配给唯一任务，也可按均衡行数重新分片。子代理按06逐条选择一个实际匹配的完整核心，核对原文，识别完整属性单元，填写Modifiers和属性数；分别处理短问、长问投放表达及问句的自然表达。按实际素材类型和等级判断分片内去重，保留来源、保留/合并/排除理由与去向。子代理返回候选结果，不直接并发改同一本最终Excel。
4. **全局汇总。** 主代理把各分片结果汇总后，按实际最终Sheet继续做跨CSV、跨分片去重，检查原问代表选择、属性与核心前后位置、部件对应关系、数值单位、否定和条件。表内无重复不等于全池无重复；不能按相同等级或相同Modifiers直接合并。核心、表达或代表原问变化时，只重算受影响记录的分级与提炼。完整相关原问池继续保留给07，不因投放去重丢失。
5. **四个复核任务。** 汇总后再创建4个子代理复核任务，优先由未整理对应分片的代理复核。按汇总后的实际行数均衡分成4份，每条记录有明确复核归属；不能只抽样。每份都从完整原文独立复算本品相关性、核心选择、属性拆分与等级，检查问句提炼是否丢条件，并核对去重去向。主代理另提供全局跨分片疑似重复对，由指定复核任务负责，不能只检查各自分片内部。并发槽位不足时分批完成这4个任务，不将分批执行称为4个同时运行。
6. **裁定与写表。** 子代理返回已核查数量及具体差异，包含来源标识、原表达、现值、建议值、原因和依据。主代理逐项核实分歧，不以多数票或代理建议直接覆盖；确认属于用户取舍的事项集中提问。核对原始来源覆盖、各来源去向、合并/排除映射和复核覆盖，修正后由主代理统一写回最终四份Excel，并核对等级页、Modifiers、统计和否定匹配方式。

各任务只写独立的步骤备份文件或返回结构化结果；备份用于续做与核验，不另生成每个CSV一份正式交付工作簿。模型设置、处理分片与复核数量如实记录在步骤备份，最终输出沿用既定四份Excel。
